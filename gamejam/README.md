# 嘻嘻狐 AI Game Jam 静态站

这是首届活动的可公开预览 MVP，适合放在现有 GitHub Pages 网站的 `/gamejam/` 子目录。

## 当前包含

- 活动首页
- 规则与 FAQ
- 作品展厅与详情页占位
- 公告、结果与历届归档
- 统一赛事数据文件 `data/site-data.js`
- 桌面端和移动端响应式布局

## 更新活动信息

编辑 `data/site-data.js` 中的 `event` 字段即可调整赛事名称、状态、截止时间、奖金和投稿表链接。投稿表链接为空时，前台按钮会显示“投稿入口准备中”。

作品和公告也暂存在同一数据文件中。公开发布前可继续使用这种结构；正式接入应援、公告后台后，再改为从 `/api/v1` 读取动态数据。

## 本地预览

在本目录运行：

```bash
python3 -m http.server 4173
```

打开 `http://localhost:4173/`。

## GitHub Pages 接入

将本目录内容复制到现有网站仓库的 `gamejam/` 目录并提交。部署完成后入口为：

```text
https://chenxiyin.com/gamejam/
```

当前版本未启用应援写入或管理员后台。GitHub Pages 是静态托管，不能安全保存所有访客共享的计数；动态功能应接入独立 API 和数据库后再开放。
